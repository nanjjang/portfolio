02 — about

필요한 기능은 직접 만들어보면서 공부합니다. 만들고 싶은 걸 먼저 문서로 적고, 범위를 정한 다음 코드를 씁니다.

Unity로 게임을 만들며 개발을 시작했고, pygame을 거쳐 지금은 백엔드와 서버 운영 쪽을 주로 봅니다. FastAPI로 API를 짜고 Svelte · Next.js로 화면을 붙이며, 최근에는 React Native와 SwiftUI로 앱도 만들고 있습니다. 블로그는 남의 플랫폼에 맡기지 않고 맥미니에 직접 띄워 Docker · Caddy · Cloudflare 터널로 운영합니다. building, breaking, fixing, learning.
